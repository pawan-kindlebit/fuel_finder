#  Fuel Finder

Fuel Finder is a mobile application that helps users quickly locate nearby fuel stations based on their current location. It provides real-time results, distance calculation, and easy navigation to the selected fuel station.

---

##  Features

-  Search for nearby fuel stations
-  Real-time location tracking
-  Map integration for better visualization
-  Distance calculation to each station
-  Navigation support (Google Maps / Apple Maps)
-  Fast and responsive UI
-  Live data updates

---

##  Tech Stack

- Frontend: Mobile App ( Android )
- Architecture: MVVM
- Maps & Location: Google Maps API / MapKit


---

##  Getting Started

### Prerequisites

- Android Studio / Xcode installed
- Google Maps API Key
- Internet connection

---

### Installation

1. Clone the repository:
   git clone https://github.com/your-username/fuel-finder.git

2. Navigate to the project directory:
   cd fuel-finder

3. Install dependencies

4. Add your API keys

---

##  Usage

1. Launch the app
2. Allow location permissions
3. View nearby fuel stations
4. Select a station for details
5. Start navigation
